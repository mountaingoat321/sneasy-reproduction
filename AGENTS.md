# Research instructions

This is an independent investigation of Wong et al. (2025), Figure 1.
Use small functions, plain data, explicit units, and the simplest numerical
method that passes meaningful verification. State boundary conditions and
separate observations, model calculations, assumptions, and inference.

These instructions apply the research principles in
[Brad Lipovsky's AGENTS.md](https://github.com/bradlipovsky/vdv-damage/blob/main/AGENTS.md).
Read [the local writing guidance](brad-lipovsky-academic-style-guide.md).
The local guidance is an original summary, not a redistributed copy of that repository.

Never access the previous reproduction project, original model code,
prepared model input bundles, posterior samples, processed simulation outputs,
or original figure files. Published manuscripts and methodological equations
are allowed. Never obtain numerical results by digitizing plots.

All project artifacts belong here. Keep downloaded literature, authentication,
caches, and launch logs out of commits. Do not alter the supplied paper.
Use one CPU for model experiments unless there is a demonstrated need for more.

Run `make all` before claiming success. A benchmark using synthetic coastlines
is not a global damage estimate and must be called a NON-REPRODUCTION.
Do not replace unavailable statistics with zero or fabricate dollar discrepancies.
